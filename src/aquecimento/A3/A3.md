## **1. É um, tem um ou guarda um? (composição, agregação e herança)**

| Par | Relação | Por quê |
| :-- | :--: | --: | 
| Gerente e Funcionario | **Herança** | Pois o Gerente `é um` Funcionario |
| Carro e Motor (o motor é criado com o carro e não existe sem ele) | **Composição** | Pois Carro `tem um` Motor, e Motor não existe fora do Carro |
| Playlist e Musica | **Agregação** | Pois Playlist `guarda uma` Musica, e uma Musica existe fora da Playlist |
| Pedido e Endereco de entrega | **Composição** | Pois Pedido `tem um` Endereco, e um Endereco não existe fora do Pedido |


## **2. Correção de Pedido**

### **2.1 Versão 1**

```java
// Versão 1 
public class Pedido extends Endereco {     
    public Pedido(Cliente comprador, String rua, int numero) {         
        super(rua, numero);     
    } 
} 
 ```
#### ☝️ Erro de modelagem, pois Pedido `não é` um Endereco. Ou seja, o relacionamento **não é uma Herança, mas sim uma composição**.

```java
// Versão 1 corrigida
public class Pedido {     
    public Pedido(Cliente comprador, String rua, int numero) {         
        this.comprador = comprador;
        this.entrega = new Endereco(rua, numero);     
    } 
} 
```
### **2.2 Versão 2**

```java
// Versão 2 
public class Pedido {     
    private String rua;     
    private int numero;     
    public Pedido(Cliente comprador, String rua, int numero) {         
        Endereco entrega = new Endereco(rua, numero);         
        this.rua = rua;         
        this.numero = numero;     
    } 
}
```

#### ☝️ Erro de implementação. Primeiro, Pedido usa rua e numero para criar uma variável Endereco entrega, mas ela não é um atributo. Segundo, Pedido salva a rua e o numero do endereco, ao invés de salvar objeto Endereco entrega e desse objeto buscar a rua e numero.

```java
// Versão 2 corrigida
public class Pedido {     
    private Endereco entrega; 
    public Pedido(Cliente comprador, String rua, int numero) {         
        this.entrega = new Endereco(rua, numero);  
        this.comprador = comprador;
    }
}
``` 

### **2.3 Versão final completa**

```java
public class Pedido {

    public Pedido(Cliente comprador, String rua, int numero){
        setComprador(comprador);
        this.entrega = new Endereco(rua, numero);
    }

    private Cliente comprador;

    public Cliente getComprador(){
        return comprador;
    }

    public void setComprador(Cliente comprador){
        if (comprador == null){
            throw new IllegalArgumentException("Comprador obrigatório");
        }
        this.comprador = comprador;
    }

    private Endereco entrega;

    public String getRuaEntrega(){
        return entrega.getRua();
    }

    public int getNumeroEntrega(){
        return entrega.getNumero();
    }
}
```
